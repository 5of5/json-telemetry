# Aria — Formal Specification

**Ariadne Transformer**  
Discrete-state mathematical description of admissible behaviors.

The following is a specification of the set of allowed infinite sequences of states. It is not a program: continuous optical and latent machinery is retained only insofar as it induces discrete state transitions that can be stated rigorously here. The continuous machinery itself — geometry, prototypes, and the refine-versus-sample stance — is specified in full in [CONTINUOUS_REFINEMENT.md](CONTINUOUS_REFINEMENT.md).

---

## 1. Abstraction Decision

We abstract the optical field \(\psi \in \mathcal{H} = \mathbb{C}^N\), the JEPA latent \(z \in \mathcal{Z}\), and the experience/thought graph \(G\) into a single typed state \(v\).

Continuous unitary evolution, prediction, matching, and diffusion are collapsed into a finite collection of named atomic actions. The grain of atomicity is one complete step of the composition

\[
\Phi = \mathrm{Diff} \circ \mathrm{Match} \circ P \circ U.
\]

Stuttering is permitted. The model exposes only those errors that would violate energy conservation, predictive contractivity, or the integrity of the experience graph.

**Preferred full-Φ schedule (𝐂4, validated):** OpticalStep → Predict → Match → Diffuse.  
This is the recommended order for one complete \(\Phi\)-step. Next remains the **disjunction** of the four actions (plus stutter); 𝐂4 is a preference among admissible schedules, not a new architecture. Operating defaults: \(\varepsilon=1\), idle Match/Diff = identity.

## 2. Deductive Axiomatization

### 2.1 Axioms (𝔸)

| Id | Statement |
|---|---|
| **𝔸1** | Optical modes form a finite-dimensional Hilbert space \(\mathcal{H} = \mathbb{C}^N\). |
| **𝔸2** | There exists a fixed isometry \(I : \mathcal{H} \hookrightarrow \mathcal{Z}\) embedding optical amplitudes into the latent space. |
| **𝔸3** | Experience is a directed typed graph \(G = (V, E)\) whose nodes carry embeddings in \(\mathcal{Z}\). |
| **𝔸4** | Every admissible optical transformation is (near-)unitary. |

### 2.2 Postulates (ℙ)

| Id | Statement |
|---|---|
| **ℙ1** | Any inner-product similarity on a finite set of modes is realizable by an optical interference circuit of depth \(O(\log N)\). |
| **ℙ2** | The predictor \(P\) is contractive on average: \(\mathbb{E}[\mathrm{Lip}(P)] \le 1\). |
| **ℙ3** | Graph edit distance is realized by a finite sequence of elementary operations (add, delete, relabel). |

### 2.3 Lemmas (𝐋)

| Id | Statement |
|---|---|
| **𝐋1** | Broadcast-and-weight ranking of a query against \(M\) keys requires only \(O(1)\) optical transit time (independent of \(M\)). |
| **𝐋2** | The residual optical paths keep analog error bounded after \(L = O(N^\alpha)\) layers for some \(\alpha > 0\). |
| **𝐋3** | Under aggressive subgraph merging the size of the persistent experience graph after \(T\) trajectories satisfies \(\lvert G \rvert = O(T^\beta)\) with \(\beta \le 1\). |

### 2.4 Theorems (𝐓)

| Id | Statement |
|---|---|
| **𝐓1** | The composition \(\Phi = \mathrm{Diff} \circ \mathrm{Match} \circ P \circ U\) is a well-defined total function on the state space of Aria. |
| **𝐓2** | Every infinite behavior generated by repeated application of \(\Phi\) preserves optical energy (up to the ideal lossless idealization) and predictive contractivity. |

### 2.5 Corollaries (𝐂)

| Id | Statement |
|---|---|
| **𝐂1** | Softmax attention is replaced by a phase-sensitive optical kernel without loss of expressive power. |
| **𝐂2** | The same latent space simultaneously supports discrete next-token prediction, continuous diffusion score estimation, and world-model roll-outs by change of conditioning alone. |
| **𝐂3** | Retrieval latency remains \(O(1)\) optical even as experience grows sub-linearly. |
| **𝐂4** | **Preferred discrete schedule.** Among the \(4!\) total orders of the four named actions realizing one complete \(\Phi\)-step, the order OpticalStep → Predict → Match → Diffuse is preferred: it is sound under Inv1–Inv4, TLC-validated on the finite instance, and maximises the `aria-math-v1` combinatorial score. Other orders remain admissible under Next; 𝐂4 does not restrict Spec. |
| **𝐂5** | **Stutter fairness budget.** Prefer at most \(K\) consecutive Stutter steps (\(K=2\) default) before a non-stutter named action. Does not remove Stutter from Next; prevents Φ-starvation under optional liveness. Falsifier: pure-Stutter infinite path when liveness is assumed. |
| **𝐂6** | **Idle efficiency.** When \(\mathrm{Res}(\psi,z,t)=0\) and no expert correction is required, Match=`identity` and Diff=`identity` minimise churn while preserving Inv1–Inv4 (v1 score 1150; v2 live synthesis). |
| **𝐂7** | **Optical-first bias among winning traces.** In extensive finite searches of Next-schedules (`aria-math-v3`), winning trajectories frequently begin with OpticalStep. Complements 𝐂4 (logical Φ composition); does not restrict Next. See [THEORIES.md](THEORIES.md). |
| **𝐂8** | **P-before-M preference inside a Φ-cycle.** Prefer schedules where Predict occurs before Match in a complete Φ-step when residual is cold (avoids Inv2 risk of Match-before-Predict with unconditioned residual). Runtime exceptions require warm residual. See [TRACES.md](TRACES.md). |

### 2.7 Optical step complexity (lemma note from v3 audit)

Under fixed optical address map with \(O(1)\) resolve (**𝐋1**):

- OpticalStep: \(\Theta(1)\) optical transit (address resolution).  
- Full preferred Φ-cycle: \(O(1 + \mathrm{cost}(P) + \mathrm{cost}(\mathrm{Match}) + \mathrm{cost}(\mathrm{Diff}))\) with Match/Diffuse costs policy-bounded (degree \(\Delta\), edit size \(m\)), **independent of \(|V|\)** when degree-bounded — consistent with **𝐂3**.

Does not change Spec transitions; records complexity justification from v3 math-audit.

## 3. Constants and Variables

### 3.1 Constants

| Symbol | Meaning |
|---|---|
| \(N\) | Number of optical modes |
| \(M_0\) | Initial bound on graph nodes |

### 3.2 Variables

\[
\begin{align*}
\psi &\in \mathbb{C}^N && \text{optical field amplitudes} \\
z &\in \mathcal{Z} && \text{JEPA latent} \\
G &\in \mathbf{Graph} && \text{experience/thought graph} \\
t &\in \mathbb{N} && \text{discrete step counter} \\
\mathit{prevRes} &\in \mathbb{N} && \text{auxiliary history for Inv2 (previous residual)}
\end{align*}
\]

Observable core: \(v = \langle \psi, z, G, t \rangle\).  
Full TLA vars: \(\langle \psi, z, G, t, \mathit{prevRes} \rangle\).  
\(\mathit{prevRes}\) does **not** enlarge observable dynamics; it names the residual compared in Inv2 ([SAFETY.md](SAFETY.md)).

Also fixed operators (constants of the theory): isometry \(I\), unitary family \(U\), predictor \(P\), \(\mathrm{Diff}\), \(\mathrm{ED}\), conditioning schedule \(a:\mathbb{N}\to\mathcal{A}\), \(\mathrm{Energy}\), distance \(d\), seed \(\psi_0,G_0\), tolerance \(\varepsilon\).

## 4. TypeOK

\[
\begin{align*}
\mathrm{TypeOK} \triangleq\;
&\;\psi \in \mathbb{C}^N \\
&\wedge\; z \in \mathcal{Z} \\
&\wedge\; G \text{ is a finite directed typed graph with node embeddings in } \mathcal{Z} \\
&\wedge\; t \in \mathbb{N} \\
&\wedge\; \mathit{prevRes} \in \mathbb{N}
\end{align*}
\]

---

## 5. Init

\[
\begin{align*}
\mathrm{Init} \triangleq\;
&\;\psi = \psi_0 \\
&\wedge\; z = I(\psi_0) \\
&\wedge\; G = G_0 \quad\text{(empty or seed graph)} \\
&\wedge\; t = 0 \\
&\wedge\; \mathit{prevRes} = d\bigl(I(\psi_0),\, P(I(\psi_0), a(0))\bigr)
\end{align*}
\]

**Theorem (Init ⇒ TypeOK ∧ Inv1–Inv4).** Immediate from domains of constants, \(z=I(\psi_0)\), well-typed \(G_0\), energy equality at \(\psi_0\), and \(\mathrm{Res}=\mathit{prevRes}\) at Init so Inv2 holds with room \(\varepsilon\).

## 6. Named Actions

The atomic steps realizing \(\Phi\).

### 6.1 OpticalStep

\[
\begin{align*}
\mathrm{OpticalStep} \triangleq\;
&\;\psi' = U_t(\psi) \\
&\wedge\; \mathrm{UNCHANGED}\langle z, G, t \rangle
\end{align*}
\]

By **𝔸4**, \(U_t\) is (near-)unitary. This is the only action that changes \(\psi\).

### 6.2 Predict

\[
\begin{align*}
\mathrm{Predict} \triangleq\;
&\;z' = P\bigl(I(\psi), a_t\bigr) \\
&\wedge\; \mathrm{UNCHANGED}\langle \psi, G, t \rangle
\end{align*}
\]

\(I\) is the fixed isometry of **𝔸2**. \(P\) is the contractive predictor of **ℙ2**. This is the sole action that updates \(z\) from the optical field.

### 6.3 Match

\[
\begin{align*}
\mathrm{Match} \triangleq\;
&\;G' = \mathrm{ED}\bigl(G \cup \{z\}, G^*\bigr) \\
&\wedge\; \mathrm{UNCHANGED}\langle \psi, z, t \rangle
\end{align*}
\]

\(\mathrm{ED}\) denotes graph edit distance realized by elementary operations (add, delete, relabel) as in **ℙ3**. This is the only action that alters \(G\).

### 6.4 Diffuse

\[
\begin{align*}
\mathrm{Diffuse} \triangleq\;
&\;z' = \mathrm{Diff}_G(z) \\
&\wedge\; t' = t + 1 \\
&\wedge\; \mathrm{UNCHANGED}\langle \psi, G \rangle
\end{align*}
\]

Diffusion is conditioned on the current experience graph. The discrete clock advances only on Diffuse.

### 6.5 Preferred full-Φ schedule (not a fifth action)

When a complete \(\Phi\)-step is intended as a single logical unit, the preferred serialisation is:

1. `OpticalStep` — \(U_t\)
2. `Predict` — \(P(I(\psi), a_t)\)
3. `Match` — \(\mathrm{ED}\) (idle default: identity; correction: one_edit / rebuild)
4. `Diffuse` — \(\mathrm{Diff}_G\) (idle default: identity)

This schedule was selected as greatest among sound configs by `aria-math-v1` and refined with stutter gates by live `aria-math-v2`. Spec still allows any interleaving admitted by Next.

### 6.6 Experience merge policy (documentation; uses only named actions)

Under **𝐋3** aggressive merge, candidate merges are realized **only** via Match / Diffuse / Stutter:

1. If latents agree within \(\varepsilon\) → Match (`identity` or `one_edit`).  
2. Else → Diffuse, then Match again.  
3. Else → Stutter, then continue the preferred Φ schedule.

No merge primitive outside the four named actions + Stutter. Cites Inv3, **ℙ3**.

### 6.7 JEPA residual score (derived; optional instrumentation)

\[
\mathrm{Res}(\psi,z,t) \triangleq d\bigl(z,\,P(I(\psi),a(t))\bigr),\qquad
\mathrm{score}_r \triangleq -\mathrm{Res}(\psi,z,t).
\]

`score_r` is not a new state variable of Spec unless an implementation chooses to log it; it is a pure function of quantities already fixed by Predict and Inv2.

## 7. Next and Spec

### 7.1 Next

\[
\mathrm{Next} \triangleq
\mathrm{OpticalStep}
\lor \mathrm{Predict}
\lor \mathrm{Match}
\lor \mathrm{Diffuse}
\lor \mathrm{Stutter}
\]

**Stutter** means \(\mathrm{UNCHANGED}\) of all Spec variables (including auxiliary \(\mathit{prevRes}\) in the TLA encoding). It is a named degenerate disjunct of Next under the usual TLA-style framing; safety properties must hold under stuttering. Stutter is **not** a fifth *architectural* action in the \(\Phi\) composition — it is idle / unobserved micro-evolution ([CONTINUOUS_REFINEMENT.md](CONTINUOUS_REFINEMENT.md) §2.5). The admissible named alphabet remains \(\{\mathrm{OpticalStep},\mathrm{Predict},\mathrm{Match},\mathrm{Diffuse},\mathrm{Stutter}\}\) only.

### 7.2 Spec

**Observable** core (documentation): \(\langle \psi, z, G, t \rangle\).  
**Full TLA vars** (machine Spec): \(\langle \psi, z, G, t, \mathit{prevRes} \rangle\) — \(\mathit{prevRes}\) is auxiliary history for Inv2 only; it does not enlarge observable dynamics.

\[
\mathrm{Spec} \triangleq
\mathrm{Init}
\land
\square[\mathrm{Next}]_{\mathrm{vars}}
\]

with \(\mathrm{vars}\) the full TLA variable tuple in `spec/Aria.tla`. Equivalent documentation form \(\square[\mathrm{Next}]_{\langle\psi,z,G,t\rangle}\) treats pure stuttering of history as covered by TLA stuttering semantics when \(\mathit{prevRes}\) is present.

No fairness is required for the safety properties in [SAFETY.md](SAFETY.md). Liveness assumptions may be added later if needed.

## 9. Relation to Continuous Machinery

Continuous Level 0–1 geometry, prototypes, refine-vs-sample stance, and Diffuse-as-atomic-sample are specified in **[CONTINUOUS_REFINEMENT.md](CONTINUOUS_REFINEMENT.md)**. That annex does **not** add actions or change Inv1–4 meanings. Summary:

| Continuous / analog construct | Discrete induction path |
|---|---|
| Unitary optical evolution / ODE multiport | OpticalStep + 𝔸4 → Inv1 |
| JEPA prediction / Lip bound / predictor flow | Predict + ℙ2 → Inv2 |
| Experience graph edits / morphism paths | Match + ℙ3 → Inv3 |
| Diffusion score/flow (one atomic sample) | Diffuse; clock \(t{+}1\); **𝐂2** by conditioning |
| Optical attention kernel (𝐂1 softened) | 𝐂1 + ℙ1; honesty in continuous annex §1.4 |
| Constant-time optical ranking | 𝐋1 → 𝐂3 |
| Idle / unobserved micro-evolution | Stutter |

**Discretization stance (design axiom):** discrete trajectories **sample** continuous prototypes at the grain of named actions; they admit continuous interpolants but Spec is not a dense time-stepper. See continuous annex §3.

Asymptotic claims derived from this structure are collected in [ASYMPTOTICS.md](ASYMPTOTICS.md).
